# SauceDemo Manual Testing Project

## 1. Project Overview

This project focuses on manual testing of the SauceDemo web application, a demo e-commerce website used for practicing software testing.

**Application Under Test:** [SauceDemo](https://www.saucedemo.com/)

**Project Type:** Manual Functional Testing

**Objective:** To verify the functionality of the application's main features, identify potential defects, and document test results using structured test cases.

## 2. Testing Scope

The testing activities will cover:

- Login and authentication
- Input validation and error messages
- Product listing and product details
- Shopping cart functionality
- Checkout process
- Navigation and logout functionality

## 3. Testing Approach

Test cases will be designed and executed manually to verify expected application behavior. Both positive and negative test scenarios will be considered.

Each test case will include:

- Test ID
- Test Scenario
- Preconditions
- Test Steps
- Test Data
- Expected Result
- Actual Result
- Execution Status

Any observed differences between expected and actual results will be investigated and documented as potential defects.

## 4. Test Environment

- **Website:** https://www.saucedemo.com/
- **Browser:** Google Chrome
- **Operating System:** Windows 11
- **Testing Method:** Manual Testing
- **Documentation:** Markdown / spreadsheet
- **Version Control:** Git and GitHub

*Note: The actual browser and operating system used during execution should be recorded accurately.*

## 5. Test Data

Test data will be selected from the demo application's provided credentials and relevant input scenarios. Credentials and input values will be documented where necessary for reproducibility.

## 6. Project Disclaimer

This is an independent learning and portfolio project conducted on a publicly available demo application. It is not an official testing engagement with Sauce Labs or the application's developers.
