# QA Testing Portfolio

## 1. Project Overview

This repository showcases my software Quality Assurance (QA) skills through practical testing activities using the SauceDemo web application, a demo e-commerce website designed for software testing practice.

**Application Under Test:** [SauceDemo](https://www.saucedemo.com/)

**Project Type:** Manual Testing, Test Automation, and Test Management

**Objective:** To practice software testing techniques, verify application functionality, document test cases, identify potential defects, and demonstrate QA tools and workflows.

## 2. Testing Scope

The testing activities cover the following areas:

- Login and authentication
- Input validation and error messages
- Product listing and product details
- Shopping cart functionality
- Checkout process
- Navigation and logout functionality
- Test case design and execution
- Automated web testing using Selenium
- Test management and issue tracking using Jira
- Bug reporting and documentation

## 3. Tools and Technologies

- **Manual Testing:** Test case design, functional testing, positive and negative testing
- **Selenium IDE:** Web test automation
- **Jira:** Test management, issue tracking, and Agile workflow practice
- **Git and GitHub:** Version control, repository management, and documentation
- **Markdown / Spreadsheets:** Test case documentation and test reports

## 5. Test Case Documentation

Manual test cases will include:

- Test ID
- Test Scenario
- Preconditions
- Test Steps
- Test Data
- Expected Result
- Actual Result
- Execution Status

Test cases will be executed and their results recorded. Any differences between expected and actual results will be investigated and documented as potential defects.

## 6. Test Environment

- **Website:** [SauceDemo](https://www.saucedemo.com/)
- **Browser:** Google Chrome
- **Operating System:** Windows 11
- **Version Control:** Git and GitHub

*The actual test environment and tools used will be documented for each relevant testing activity.*

## 7. Project Disclaimer

This is an independent learning and portfolio project conducted on a publicly available demo application. It is not an official testing engagement with Sauce Labs or the application's developers.

The repository demonstrates my learning and practical application of QA techniques. Testing results and defect reports will reflect actual observations made during test execution.
